\title{The Wald Test}

\begin{document}

Recall that a test $\Psi$ has level $\alpha$ if
$\mathrm{size}(\Psi) \leq \alpha$, where
$\mathrm{size}(\Psi) := \max_{\theta \in \Theta_0} \mathbb{P}_{\theta}(\Psi = 1)$
is the maximum possible probability of a Type I error
(when $H_0$ is true yet $\Psi = 1$).
Also recall that the standard error of an estimator $\hat{\theta}$
is $\mathrm{se} := \sqrt{\mathbb{V}[\hat{\theta}]}$.

\begin{theorem}{The Wald Test}
    Suppose $\hat{\theta}$ is an asymptotically normal estimator of $\theta$,
    and we seek a test $\Psi$ with level $\alpha$.
    Note that this means $\frac{\hat{\theta} - \theta}{\widehat{\mathrm{se}}}
    \rightsquigarrow \mathcal{N}(0, 1)$. Then
    $T_n := \frac{\hat{\theta} - \theta_0}{\widehat{\mathrm{se}}}$
    is our test statistic, and our test $\Psi$ is defined by\dots
    \begin{itemize}
        \item \dots if we seek the hypotheses $H_0: \theta = \theta_0$
        and $H_1: \theta \neq \theta_0$, then
        $\Psi := \mathds{1}\left(|T_n| \geq z_{\alpha / 2}\right)$, where
        $\Phi(z_{\alpha / 2}) - \Phi(-z_{\alpha / 2}) = 1 - \alpha$.
        \item \dots if we seek the hypotheses $H_0: \theta \leq \theta_0$
        and $H_1: \theta > \theta_0$, then
        $\Psi := \mathds{1}\left(T_n \geq z_{\alpha}\right)$, where
        $\Phi(z_{\alpha}) = 1 - \alpha$.
        \item \dots if we seek the hypotheses $H_0: \theta \geq \theta_0$
        and $H_1: \theta < \theta_0$, then
        $\Psi := \mathds{1}\left(T_n \leq -z_{\alpha}\right)$, where
        $\Phi(-z_{\alpha}) = \alpha$.
    \end{itemize}
\end{theorem}

If you really wanted, you could also compute the power $\beta(\theta)$ of each of the above tests.

\begin{remark}
    How do we actually compute an estimate $\widehat{\mathrm{se}}$
    of the standard error?
    \begin{itemize}
        \item If $\hat{\theta}$ is $\bar{X}_n$,
        then we can use standard techniques:
        \href{1-3.html#applying-slutsky-s-theorem}{calculate the sample variance} $s_n^2$
        and estimate $\widehat{\mathrm{se}} = \frac{s_n}{\sqrt{n}}$.
        \item If $\hat{\theta}$ is the MLE,
        then compute $I(\hat{\theta})$ and declare that
        $\widehat{\mathrm{se}} = \frac{1}{\sqrt{n \cdot I(\hat{\theta})}}$.
        \item Otherwise, use bootstrapping:
        draw $B$ bootstrap samples, compute $\hat{\theta}_b^*$ for each,
        and set $\widehat{\mathrm{se}} = \sqrt{
            \frac{1}{B - 1} \sum_{b = 1}^B \left(\hat{\theta}^*_b - \bar{\theta}^*\right)^2
        }$.
    \end{itemize}
\end{remark}

The \textbf{Z-test} is the special case of the Wald test
when the test statistic looks like $T_n = \frac{\bar{X}_n - \mu_0}{\sigma / \sqrt{n}}$
and when $\sigma$ is the true, \emph{known} population standard deviation.
